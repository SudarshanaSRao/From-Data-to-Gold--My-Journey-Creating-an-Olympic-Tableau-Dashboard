# From-Data-to-Gold--My-Journey-Creating-an-Olympic-Tableau-Dashboard
This repository showcases the **Tableau dashboard** I created to analyze Olympic data. The dashboard offers interactive visualizations to uncover insights from Olympic history, such as medal counts, country performances, and event trends over the years.

## [Medium blog post](https://medium.com/@sudarshanasrao/olympics-tableau-3a79b7b49619)

![dash](https://github.com/user-attachments/assets/ddcfe858-b3ec-487e-9207-181157347929)

## Key Features
- Medal counts by country, year, and event.
- Athlete performance trends over the years.
- Comparative analysis of countries’ Olympic successes.
- Insights into event popularity and how it evolved across different Olympic Games.
